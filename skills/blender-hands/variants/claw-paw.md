# Variant: claw / paw (creatures)
| Topic | Rule |
|---|---|
| Digits | 3-5 digits; each digit like a finger with 2 joint zones; sides 4-6 for Low |
| Claws | cone or curved cone: sides 4-6, tris = 2 x sides x rows (rows 2-3) + tip, about 8-20 each [COMPUTED] |
| Paw pad | part of the palm geometry; one quad-only patch on the underside |
| Toe pads | texture (Low/Mid), 4-8 tri plates (Hero) |
| Rig | 2 bones per digit (Reduced) or 3 (Full) + paw bone |
| Pitfall | claws as separate meshes break bake and weights: merge into the digit mesh or parent rigidly |
