# Variant: cartoon 4-finger (3 fingers + thumb)
| Topic | Rule |
|---|---|
| Fingers | 3 fingers + thumb; thick (finger width about 0.25 of palm width [START]) |
| Sides | 6 (Low) or 8 (Mid); L = 2 |
| Palm | big and round; webbing minimal |
| Tris | fingers sum = 3 x finger + thumb (hand-topology.md section 2), then palm 80-160 [START] |
| Rig | 3 bones per finger or 2 (Reduced); thumb 2 |
| Pitfall | thick fingers need rows between joints at least 1 or the curl looks like a hinge |
