# Locomotion cycles [START] (at 30 fps; scale frames by fps/30)

| Clip | Frames (full cycle) | Seconds | Key poses |
|---|---|---|---|
| Idle (breathing) | 60-120 | 2-4 | neutral, inhale up, exhale down, neutral |
| Walk | 24-36 | 0.8-1.2 | contact, down, passing, up, contact (mirrored for the other leg) |
| Run | 16-24 | 0.5-0.8 | contact, down, passing, up (flight phase), contact |
| Jump | 20-40 | 0.7-1.3 | anticipation, takeoff, apex, fall, landing |
| Turn in place | 12-24 | 0.4-0.8 | anticipation, pivot, settle |
Rules: left and right halves mirror; the cycle returns to the first pose; feet planted on contact frames (no slide: stride length x frequency = travel speed).
Quick check: travel speed = stride length / half-cycle time.
