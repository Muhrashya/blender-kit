# Variant: creature (animals, monsters)

| Topic | Rule |
|---|---|
| Skeleton first | decide spine, limbs, tail, jaw, wings; loops go where those bones bend |
| Symmetry | mirror one half; center line on x = 0 |
| Limbs | same joint-loop rules as characters (deformation-zones.md Mid or Hero) |
| Head | loops around eyes and mouth; jaw hinge region quads only |
| Tail / tentacles | tube rings every segment of bone length / 2; ring vertex count constant |
| Digits (claws, paws) | blender-hands variants/claw-paw.md |
| Sculpt source | if a sculpt exists: blender-retopo |
| Pitfalls | unequal ring counts along tubes, poles in the neck/shoulder, ngon in the mouth |
