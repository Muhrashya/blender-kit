# Style: stylized (hand-painted or toon, readable shapes)

| Topic | Rule |
|---|---|
| Geometry | simplified, slightly exaggerated proportions; soft bevels carried by smooth shading, not geometry |
| Textures | hand-painted base color (shading painted in); little or no metal/roughness; optional gradient ramp for toon shading in engine |
| Normal maps | optional, for edge highlights only |
| Silhouette | the main quality target: it must read in a black-fill test |
| Rig | 2-3 loops at bending joints for characters (Mid column of deformation-zones.md) |
| Hands | 4 or 5 fingers, thick, 6-8 sides, 2 loops per joint |
| Triangle strategy | budget goes to silhouette curves and deformation zones; flat areas get nothing |
| Pitfalls | texture-painted shadows break when lighting changes: keep painted shading subtle |
| Audit overrides | none |
