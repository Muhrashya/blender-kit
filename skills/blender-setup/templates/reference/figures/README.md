# Figures

Generated by `python3 tools/make_figures.py` (needs numpy + matplotlib) from the kit's own tables and constructed meshes. The script verifies the transition patterns and checks the hand-tier numbers against hand-topology.md, and fails if they disagree.

| File | Shows | Used by |
|---|---|---|
| pipeline.png | skill graph, fail routes, interrupt rule | router, build-guide.md |
| transition-patterns.png | verified quad loop transitions, normal + subdivided | transition-patterns.md |
| joint-loops.png | loops straddling a joint per tier, no-pole zone | deformation-zones.md |
| rig-ready-zones.png | pole-free zones and parking areas on a humanoid | deformation-zones.md |
| finger-tiers.png | ring layout per hand tier with triangle counts | hand-topology.md |
| hand-layout.png | hand rest pose, joint zones, thumb angle | hand-topology.md |
| camera-moves.png | 12 camera moves: what moves, what stays | blender-camera |
| vfx-life-curve.png | build/peak/fade curve + layer timeline | vfx-styles.md, cookbook |
| vfx-style-compare.png | realistic, stylized, low-poly, voxel looks | vfx-styles.md |
| verified-patterns.json | verification data for each pattern | transition-patterns.md |
